Throwaway test assets for [issue #17](https://github.com/Blind3y3Design/design-review-skills/issues/17). They aren't Review Skills.

| File | Purpose |
|---|---|
| `drs-test-fetch.md` | Test skill. Reads each target document by a named method and reports its codeword. |
| `drs-test-connector-write.md` | Test skill. Tries to create a Notion page, a GitHub issue, a GitHub file and a Google Doc. |
| `reference-raw.md`, `reference-connector.md`, `reference-shell.md` | Target Reference Documents for F1–F3, each with its own codeword. |
| `profile-raw.md`, `profile-connector.md` | Target Review Profiles for P1–P2, each with its own codeword and accessibility target. |

The Google Drive and Notion targets (F4, F5) are created by hand and aren't in the repo, so their codewords can't leak through the GitHub connector. The results are recorded in the resolution comment on issue #17.
