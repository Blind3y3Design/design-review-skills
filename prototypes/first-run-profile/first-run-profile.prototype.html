First-run Review Profile: a prototype (version 3)

Throwaway prototype for issue #12. The file, its libraries and the answers are made up. Nothing here is saved anywhere.

The question: when there's no Review Profile, what should the conversation that creates one ask, in what order, and who asks it? And how does a Review Skill run on its own behave with and without a profile? Pick how the review starts and whether a profile already exists, then step through it. Watch who asks each question, the transcript, the document being written, and the readiness check for each review.

Changed since version 1, from your reviews:

  • Step by step only. Compact mode is gone.
  • "Not now" is gone. The Orchestrator needs a profile. A Review Skill run on its own can run without one, and asks what to check against instead.
  • Each Review Skill asks its own set-up questions (shown by the speaker label), and the Orchestrator asks the shared ones and writes the profile.
  • A skill run on its own never writes to a profile. The Orchestrator can add a missing section.
  • Layer owners aren't asked for. A Finding names the layer, and the designer knows which team that is.
  • A library the ordering rule can't place is asked about, not guessed.
  • The profile is written for agents: fixed headings, one setting per line, and one plain sentence per section for the people who maintain it.
  • In Figma, the profile is always saved as a "Review Profile" page in the file. The custom skill option is gone. A shared profile hosted on GitHub is a later enhancement.
